# arkit-recorder v2.3 일시정지 상태 버튼 설계

날짜: 2026-08-05
상태: 승인됨 (사용자 레이아웃 지정)
기반: 2026-08-05-pause-scrub-design.md (v2.2)

## 1. 목적

일시정지 상태가 컨트롤 바에 명시적으로 보이도록, 루프처럼 체크형 상태 버튼으로 추가한다.
버튼 순서: **[재생] [일시정지] [정지] [루프]**.

## 2. 동작

- **일시정지 버튼** (checkable, 아이콘 SP_MediaPause):
  - 재생 중 클릭(체크) → 현재 플레이헤드 프레임에서 일시정지
    (v2.2의 스크럽 일시정지와 동일 상태: begin_scrub로 플레이어 정지, 해당 프레임
    1회 송출 + 킵얼라이브 고정, 위젯 paused)
  - 일시정지 중 클릭 해제 → 그 위치부터 재개 (기존 `_on_play` 재개 경로 재사용)
  - 재생/일시정지가 아닌 상태에서 체크 시도 → 즉시 체크 해제 (무동작)
- **상태 동기화**: poll이 `setChecked(paused)`로 버튼을 상태에 맞춤
  (스크럽으로 진입한 일시정지도 자동 반영. `clicked` 시그널은 사용자 클릭에만
  발화하므로 프로그램적 setChecked와 충돌 없음)
- 활성 조건: PLAYING이거나 paused일 때만 활성
- 기존 [정지]의 일시정지 해제(라이브 복귀), 스크럽 일시정지 진입은 무변경

## 3. 구현 포인트

- `TimelineWidget.pause_at_playhead() -> bool` — begin_scrub 성공 시 플레이헤드
  위치 프레임(frame_index_at)을 scrub_frame으로 1회 송출하고 paused 진입
  (킵얼라이브 시작). 실패(모드 부적합/데이터 없음) 시 False
- `MainWindow._on_pause(checked)` — 위 §2 로직. 버튼은 `clicked` 시그널 연결
- 컨트롤 바 배치 순서 변경, poll에 setChecked/setEnabled 추가

## 4. 테스트

- 코어 무변경 (기존 92개 유지). GUI는 수동 스모크:
  재생→일시정지 버튼→고정 확인→해제→재개 / 스크럽 일시정지 시 버튼 자동 체크 /
  정지로 해제 시 버튼 해제
